# Welcome To My University Repository!

## English:

Over the course of the next days (or weeks), I’m going to deposit some things here that I would like to (or will need to) use for the upcoming semester at my university. One of these will be a template for a seminar paper that is due by the end of August of this year, once using LaTeX and once using Word (just in case if LaTeX drives me too crazy or if my professor insists on a Word document).
